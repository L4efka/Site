Політика конфіденційності розширення «Помічник вчителя»

Дата набрання чинності: 19 листопада 2026 р.

Ця Політика конфіденційності описує, як браузерне розширення «Помічник вчителя (Classroom • NZ.ua • MeetList)» (далі — «Розширення») обробляє та захищає дані користувачів.

1. Загальні принципи (Локальна обробка даних)

Розширення створене для автоматизації рутинної роботи вчителів між сервісами Google Classroom, NZ.ua («Нові Знання») та MeetList.io.
Ми НЕ збираємо, НЕ зберігаємо на зовнішніх серверах, НЕ передаємо третім особам і НЕ продаємо жодні персональні дані користувачів або учнів.

Уся обробка інформації відбувається виключно локально у вашому браузері на вашому пристрої.

2. Які дані обробляються локально в браузері

Для виконання своїх основних функцій Розширення тимчасово або локально зберігає в сховищі браузера (chrome.storage.local) лише ті дані, з якими ви безпосередньо працюєте:





Оцінки та імена учнів із Google Classroom: тимчасово зберігаються в локальному буфері браузера після натискання кнопки копіювання (або завантаження CSV-файлу), щоб перенести їх у вибраний стовпчик журналу nz.ua.



Список учасників онлайн-уроку з MeetList.io: тимчасово зберігається локально для підрахунку кількості присутніх учнів та звірки зі списком класу на nz.ua.



Резервний буфер стовпчика nz.ua: тимчасово зберігає видалені вами оцінки або відмітки (Н, ХВ) одного стовпчика, щоб ви могли відновити їх у разі помилкового видалення.



Ваші локальні налаштування: обраний дільник балів, правило округлення («на користь учня» чи ні), прапорець захисту відміток «Н» та ваші власні назви для кодів зустрічей Google Meet (наприклад, gzu-ummj-oah → Інформатика 8-А).

Ці дані ніколи не залишають межі вашого браузера і можуть бути очищені в будь-який момент кнопкою «Очистити» в інтерфейсі Розширення або шляхом видалення Розширення.

3. Дозволи браузера та їх використання

Розширення запитує лише мінімально необхідний набір дозволів:





storage — для локального збереження буфера перенесення оцінок, резервної копії стовпчика, прив'язок кодів Google Meet та ваших налаштувань.



activeTab / tabs — для визначення активної вкладки (classroom.google.com, nz.ua, meetlist.io) та обміну командами між вікном розширення та сторінкою.



scripting — для коректного підключення інструментів розширення до відкритих вкладок підтримуваних освітніх платформ.



Доступ до доменів (https://classroom.google.com/*, https://*.nz.ua/*, https://*.meetlist.io/*) — використовується виключно для зчитування/ділення оцінок у Google Classroom, аналізу присутності/перейменування зустрічей у MeetList.io та вставки/очищення оцінок в електронному журналі NZ.ua. Розширення не має доступу до жодних інших вебсайтів.

4. Передача даних третім сторонам та аналітика





Розширення не містить рекламних модулів, трекерів, Google Analytics чи будь-яких інших систем телеметрії.



Розширення не надсилає жодних мережевих запитів на сторонні сервери розробника.



Розширення відповідає вимогам Chrome Web Store User Data Policy, зокрема вимогам Limited Use.

5. Зміни в Політиці конфіденційності

У разі додавання нових функцій ця Політика конфіденційності може оновлюватися. Актуальна версія завжди публікується разом із Розширенням.

6. Контакти

Якщо у вас виникли запитання щодо цієї Політики конфіденційності або роботи Розширення, ви можете звернутися до розробника через сторінку підтримки Розширення в Chrome Web Store.



Privacy Policy — «Помічник вчителя» (Teacher's Assistant)

Effective Date: November 19, 2026

This Privacy Policy explains how the «Помічник вчителя (Classroom • NZ.ua • MeetList)» browser extension (the "Extension") handles user data.





No Data Collection or External Transmission: The Extension operates 100% locally inside your browser. We do not collect, transmit, store on external servers, sell, or share any personal data, student names, grades, or browsing history with any third parties.



Local Storage Only (chrome.storage.local): The Extension uses the browser's local storage solely to temporarily hold copied grades from Google Classroom, attendance lists from MeetList.io, a local undo buffer for cleared NZ.ua columns, user-defined Google Meet code labels (e.g., mapping a Meet code to a class/lesson name), and user preferences (divisor, rounding mode). All data stays strictly on your device.



Host Permissions: Access is strictly limited to classroom.google.com, nz.ua, and meetlist.io to perform user-initiated grade transfer, grade division, attendance matching, and column management.



Compliance: The use of information accessed by the Extension strictly adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
